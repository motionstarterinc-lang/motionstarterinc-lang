## Projects

### 🔍 [web-vuln-scanner](https://github.com/motionstarterinc-lang/web-vuln-scanner)
A lightweight, defensive web security scanner built in Python. Checks a site's own public configuration for common weaknesses -- missing security headers (CSP, HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy) and commonly exposed paths (like `/.git/config`). Read-only -- it doesn't attack or exploit anything; built and tested only against systems I own or have permission to test.

**Tech:** Python, `requests`

### 📡 [scapy-packet-handshake](https://github.com/motionstarterinc-lang/scapy-packet-handshake)
A small Python toolkit using Scapy to hand-craft raw packets and walk through the TCP 3-way handshake byte by byte -- built to actually understand what SYN, SYN-ACK, and ACK are doing at the packet level, not just know the terms.

**Tech:** Python, Scapy

### 🏢 [ado-management](https://github.com/motionstarterinc-lang/ado-management)
A platform to help students track, submit, and stay on top of accessibility/disability services (ADS/ADO) accommodations each semester.
